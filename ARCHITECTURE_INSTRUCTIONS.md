# Инструкция по архитектурной переработке

## 0. Правила

- Не менять поведение игры без отдельной задачи.
- Делать миграцию маленькими шагами.
- После каждого шага запускать ручную проверку в браузере.
- Не смешивать перенос файлов и изменение логики в одном шаге.
- Новую игровую логику писать без DOM, Canvas, Firebase и `localStorage`.
- Firebase не должен быть обязательным для запуска игры.
- Новый уровень добавлять через конфиг.
- Новый вариант игры добавлять через режим.
- Каждую чистую функцию покрывать unit-тестом.

## 19. Финальный критерий

- `index.html` содержит только разметку и подключения.
- CSS разнесен по файлам.
- `src/main.js` только связывает модули.
- Уровни находятся в `src/game/levels.js`.
- Режимы находятся в `src/game/modes.js`.
- Музыкальная логика находится в `src/game/`.
- Отрисовка находится в `src/ui/`.
- Хранилища находятся в `src/services/`.
- Firebase отключается без поломки игры.
- Все текущие уровни покрыты тестами.
- Новый уровень добавляется без изменения движка.
- Новый режим добавляется без изменения существующих режимов.
