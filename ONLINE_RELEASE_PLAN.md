# План выхода онлайн

Цель: опубликовать игру как реальную веб-страницу с работающей онлайн-таблицей лидеров и четырьмя уровнями игры.

## 1. Выбрать хостинг

Подойдет любой статический хостинг:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

Проект не требует серверной сборки: достаточно отдать `index.html`, `src/`, `package.json`, `README.md` и связанные файлы.

## 2. Создать и настроить Firebase-проект

1. Создать проект в Firebase Console.
2. Включить Firestore Database.
3. Выбрать production mode.
4. Создать коллекцию `leaders` или позволить приложению создать ее при первой записи.

## 3. Вставить реальный Firebase config

В файле `src/config.js` заменить значения `PASTE_...` на реальные значения из Firebase:

```js
export const firebaseConfig = {
  apiKey: '...',
  authDomain: '...',
  projectId: '...',
  storageBucket: '...',
  messagingSenderId: '...',
  appId: '...',
};
```

Пока в конфиге стоят `PASTE_...`, игра работает только с локальной таблицей лидеров.

## 4. Создать Firestore index

Для запросов лидерборда нужен составной индекс:

- `level` ascending
- `score` descending
- `date` ascending

Если индекс не создан заранее, Firestore обычно покажет ссылку на создание индекса в ошибке запроса.

## 5. Опубликовать Firestore rules

В Firebase Console опубликовать правила из файла `firestore.rules`.

Правила разрешают публичное чтение лидерборда и ограничивают запись только валидными результатами:

- имя от 1 до 20 символов;
- счет от 0 до 240;
- уровень только `easiest`, `easy`, `medium`, `hard`;
- запрещены update/delete существующих записей.

## 6. Залить проект на хостинг

Перед публикацией выполнить:

```powershell
npm.cmd test
```

Затем загрузить проект на выбранный хостинг. Для локальной проверки:

```powershell
npm.cmd run dev
```

Локальный адрес:

```text
http://127.0.0.1:4173/
```

## 7. Проверить публичный URL

После деплоя открыть публичный адрес и проверить:

- страница загружается без битой кодировки;
- доступны все четыре уровня;
- раунд начинается после countdown;
- результат сохраняется после окончания игры;
- таблица лидеров загружается с Firebase;
- при временной ошибке Firebase игра продолжает работать с локальной таблицей.

## Готовность

Проект считается готовым к нормальному онлайн-запуску, когда:

- `npm.cmd test` проходит без ошибок;
- `src/config.js` содержит реальный Firebase config;
- Firestore rules опубликованы;
- Firestore index создан;
- публичный URL открывается;
- новый результат появляется в онлайн-таблице лидеров.
