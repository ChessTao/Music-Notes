# Учим ноты

Браузерная игра для тренировки чтения нот. Игрок выбирает один из четырех уровней, отвечает на нотные задания с виртуальной клавиатуры и попадает в локальную или онлайн-таблицу лидеров.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте `http://127.0.0.1:4173/`.

## Проверка

```powershell
npm.cmd test
```

## Онлайн-таблица

Firebase выключен, пока в [src/config.js](src/config.js) стоят значения `PASTE_...`. Чтобы включить онлайн-таблицу:

1. Создайте Firebase-проект и Firestore Database.
2. Заполните `firebaseConfig` в [src/config.js](src/config.js).
3. Создайте коллекцию `leaders`.
4. Добавьте индексы Firestore для запросов: `level ASC`, `score DESC`, `date ASC`.
5. Опубликуйте правила из [firestore.rules](firestore.rules) или перенесите из них проверки в свои правила проекта.

Без Firebase игра продолжает работать с локальной таблицей в `localStorage`.

## Проверка перед правками

- Запустить `npm.cmd test`.
- После изменения `src/game/levels.js` вручную проверить все четыре уровня в браузере.
- После изменения `src/services/` проверить локальную таблицу, очистку и режим без Firebase.
- После изменения `src/ui/staffCanvas.js` проверить отрисовку скрипичного и басового ключа.
- После изменения `src/ui/keyboard.js` проверить клики по белым и черным клавишам.
