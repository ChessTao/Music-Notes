# Учим ноты

## Проверка перед правками

- Запустить `npm test`.
- Если появится линтер, запускать `npm run lint`.
- Если появится форматтер, запускать `npm run format`.
- После изменения `src/game/levels.js` вручную проверить все уровни в браузере.
- После изменения `src/services/` проверить локальную таблицу лидеров, очистку и режим без Firebase.
- После изменения `src/ui/staffCanvas.js` проверить отрисовку скрипичного и басового ключа.
- После изменения `src/ui/keyboard.js` проверить клики по белым и черным клавишам.
